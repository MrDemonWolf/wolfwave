## Report a bug

Something broke? A clear report saves hours.

1. Open **Settings → Advanced** and use the bug-report flow. It pre-fills a GitHub
   issue with your app version and system info. If you've turned on the opt-in
   diagnostics, you can attach the on-device diagnostic export too — nothing is
   sent anywhere until you decide to share it.
2. Or file directly: [open an issue](https://github.com/MrDemonWolf/wolfwave/issues/new)
   with what you did, what you expected, and what happened.
3. Prefer chat? Ask in the [community Discord](https://mrdwolf.net/discord).
