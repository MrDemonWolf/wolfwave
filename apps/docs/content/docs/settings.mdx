**TL;DR:** For streamers looking for a switch. Each section below is one Settings pane: what's in it and where to read more.

**Open Settings:** click the wolf icon in your menu bar, then **Settings…**. The sidebar groups the panes: **General**; **Integrations** (Twitch, Discord); **On Stream** (Stream Widgets, Stream Deck, Song Requests); **Insights** (History & Stats); and **App** (Software Update, Advanced, About).

Settings use native macOS switches with attached labels and wrapping descriptions. Disabled options follow the system appearance.

The toolbar names the selected pane. The window supports widths down to 640 points for compact or half-screen use, with integration status and actions stacked when needed. Hide the sidebar with its toolbar button to give the current pane more space.

Each pane also has a `wolfwave://` link that opens WolfWave right to it. See [Deep links](#deep-links).

## General

<small>Open in WolfWave: [`wolfwave://settings/general`](wolfwave://settings/general)</small>

How WolfWave tracks your music and where it shows up.

- **Sync Music.** The main switch. On by default. A row under it shows your Music access: **Music access on** (with **Recheck**), or **Allow** the first time macOS asks.
  - Access off? A banner appears. Click **Open System Settings**, turn on Music under WolfWave in Automation, then click **Try again**. **Show me how** walks you through it.
- **Live from Apple Music.** The song, artist, album, and art WolfWave sees right now.
- **Integrations.** One row each for Twitch chat, Discord profile, and Stream Widgets. A chip shows the state: **Live**, **Showing now**, **Ready for OBS**, or **Off** (**Paused** while Music access is missing). **Configure** jumps to that pane.
- **App Visibility.**
  - **Launch at Login:** start WolfWave when you log in. If macOS blocks it, use **Open Login Items**. If macOS wants your OK, use **Approve in Login Items…**.
  - **Display mode:** **Dock and Menu Bar** (default), **Menu Bar Only**, or **Dock Only**. **Dock Only** is greyed out while Launch at Login is on, so the menu bar icon is always there. Turning Launch at Login on while in Dock Only switches you to Dock and Menu Bar.
  - Menu Bar Only temporarily shows the Dock icon while Settings is open.
  - The Dock icon has its own menu. See [the Dock menu](/docs/features#menu-bar-and-music-sync).
- **Appearance.** Applies to the whole app, menu included.

  | Option | What it does |
  |---|---|
  | **System** (default) | Matches macOS, including its light/dark schedule. |
  | **Light** | Always light. |
  | **Dark** | Always dark. |

- **Notifications.** Mac banners, all off by default:
  - **Song change notifications**
  - **Skip vote started** and **Skip vote passed** (greyed out until you turn on vote-to-skip in Song Requests)
  - macOS asks for permission the first time you turn one on. If macOS blocks banners, a warning offers **Open System Settings**.
  - One banner has no switch: **Twitch Authentication Expired** appears if your Twitch sign-in lapses, as long as macOS already lets WolfWave post notifications.

These preferences are included in [Back Up & Restore](/docs/backup).

## Song Requests

<small>Open in WolfWave: [`wolfwave://settings/song-requests`](wolfwave://settings/song-requests)</small>

Let chat request songs. How it all works: [Song requests](/docs/features#song-requests).

**First time?** Click **Set Up Song Requests**. The setup has these steps:

1. **Get started.** Checks Twitch. Not connected? Click **Open Twitch Settings**, sign in, then come back.
2. **Apple Music access.** Click **Grant Apple Music Access**. If you denied it before, turn on WolfWave in **System Settings → Privacy & Security → Media & Apple Music**. (This is separate from the Automation access that Sync Music uses.)
3. **Requests playlist.** Makes the **WolfWave Requests** playlist, then waits up to about 40 seconds for Music on this Mac to pick it up. Still not there? Turn on **Music → Settings → General → Sync Library** and click **Check Again**. You can finish setup either way.
4. **Share link** (optional). Lets `!playlist` post a link in chat.
5. **All set.** Click **Turn On Song Requests**.

Want to change something later? Click **Run Setup Again** under **Enable Song Requests**.

**After setup**, the pane lists the live queue first, then the switch and vote-skip, then the rest grouped by task:

- **Song Request Queue.** The live queue, with its controls above the song list. **Hold** (or **Resume**) keeps requests coming in but stops them playing. You can hold before the first request arrives. **Skip** shows while a request is playing. **Clear Requests** asks first, then empties the queue and **WolfWave Requests** together. If any requests are queued, waiting, or playing, it stops Music too. If there are none, Music keeps playing. Songs stay in your library. With **Require My Approval** on, waiting requests show here with **Approve** and a decline button.
- **Enable Song Requests.** The master switch, **Run Setup Again**, and **Reply When Off**, which makes `!sr` answer "Song requests are off right now." while requests are off.
- **Chat Vote-Skip.** **Enable Vote-Skip**, **Minimum votes to skip**, **Subscriber-Only Voting**, and **Use Twitch Polls** (then pick a **Poll duration**). With a chat tally you also set the vote window and a **Cooldown between votes**. The `!voteskip` command has its own switch and aliases. Works even with requests off.
- **Request setup:** **Who Can Request** sets a preset and approval; **Song Request Commands** manages `!sr`, `!queue`, `!myqueue`, `!skip`, `!clearqueue`, and `!playlist`; **Channel Points & Bits** configures paid requests.
- **Queue behavior:** **Queue Settings** controls ordering, priority, capacity, and per-user limits. **Playback** controls **Hold Queue**, **Auto-Advance Queue**, **Resume Apple Music AutoPlay**, and a **Fallback playlist**. Enable AutoPlay in Music's Playing Next panel; a fallback playlist takes priority.
- **Moderation:** **Blocklist** blocks a **Song**, **Artist**, or **Person**. Press Return to add.

**Per-user limits, explained:**

- Each role (Everyone, Subscribers, VIPs, Moderators) can have its own limit: 1, 2, 3, 5, 10, 15, or 20. **Max queue size** is 5, 10, 15, 20, 25, or 50.
- When a viewer has more than one role, choose:
  - **Highest tier:** they get their best role's limit. A role you haven't set counts as 2.
  - **Stacked:** start from Everyone and add each role's extra slots. A role you haven't set shows **None** and adds nothing.

Chat commands: [Bot Commands](/docs/bot-commands).

## Stream Widgets

<small>Open in WolfWave: [`wolfwave://settings/stream-widgets`](wolfwave://settings/stream-widgets)</small>

Your OBS overlay. Cards are in the order you need them:

1. **Enable Stream Widgets.** Starts the connection the overlay uses.
2. **Widget Setup.** Turn on **Enable Widget Webpage**, then **Copy Link**. The OBS steps are in [Now-playing widget](/docs/features#now-playing-widget). **Widget Port (Advanced)** is here too. **Network Address** is for two-PC setups on a network you trust.
3. **Widget Appearance.** Theme, layout, colors, and font, with a live preview. Your edits wait until you click **Apply**. The pane says "Unsaved changes" until then, and **Revert** drops them.
4. **Build your own overlay.** The raw feed: port, read-only **Overlay Token**, and the local and network addresses. Only needed for a hand-made overlay. Edit the token by hand and click **Save**, or **Regenerate** it. Regenerate asks first, and active overlays disconnect until you copy the new link back into OBS.

**The status chip on the first card shows the server state:**

- **Listening** (or **N connected** once an overlay joins)
- **Starting**
- **Stopped**
- **Couldn't start.** Usually a busy port. See [Port already in use](/docs/troubleshooting#port-in-use).

Other tips:

- To change the widget port, turn off **Enable Widget Webpage** first. To change the raw-feed **Port** in Build your own overlay, turn off **Enable Stream Widgets** first. A bad port is put back, and the field says **Saved** or **Not saved**.
- A greyed-out button tells you what to turn on first.

Sizes, themes, and messages: [OBS Widget](/docs/widget).

## Stream Deck

<small>Open in WolfWave: [`wolfwave://settings/stream-deck`](wolfwave://settings/stream-deck)</small>

Control WolfWave from a Stream Deck.

- **Allow Stream Deck commands.** On by default. Turning it off leaves your overlay running.
- **Stream Deck Control Token.** Paste it into the plugin. Treat it like a password. It only works from this Mac.
- **Stream Deck Setup Guide.** Step-by-step setup.

Why it's separate from Stream Widgets: the overlay token is read-only and can reach across your network. The control token runs commands, so it only works on this Mac.

**The status chip at the top names the first thing in your way:**

1. **Server off.** Turn on Stream Widgets.
2. **Server error.** The server couldn't start (often a busy port). Use **Open Stream Widgets**.
3. **Starting.**
4. **Commands off.** Turn on Allow Stream Deck commands.
5. **Ready.** Only shows when the server is really running.

Full walkthrough: [Stream Deck](/docs/streamdeck).

## History & Stats

<small>Open in WolfWave: [`wolfwave://settings/history-stats`](wolfwave://settings/history-stats)</small>

Your listening history, kept on this Mac.

- **Listening History.** Off by default. Turn it on to start recording plays. Your latest plays show under **Recently played**.
- **Show Stats & Charts.** Needs Listening History on. Weekly view, top artists, listening by hour, and the Monthly Wrap.
- **!stats command.** Off by default. Chat can use it once Twitch is connected. Pick the time window and what chat sees. Keep at least one item selected.
- **Keep for.** How long to keep plays: **Forever**, or 7 to 365 days. A shorter window asks first if it would remove plays.
- **Danger Zone → Clear History**. Deletes every play. Can't be undone.

What counts as a play: [Listening History](/docs/listening-history).

## Twitch

<small>Open in WolfWave: [`wolfwave://settings/twitch`](wolfwave://settings/twitch)</small>

Connect your Twitch account and set up the chat bot.

**Sign in:** follow the steps in [Twitch chat bot](/docs/features#twitch-chat-bot).

**Once you're signed in:**

- **Bot account** shows who posts the replies.
- **Leave Channel** disconnects the bot from your channel but keeps you signed in. It asks "Disconnect from channel?" first. To switch channels, leave, type the new name, then click **Join Channel**.
- **Log Out** asks "Sign out of Twitch?" first. Chat commands stop until you sign in again.

**Below the sign-in card:**

- **Chat commands.** **Only reply while live** keeps every command quiet until you go live. Off by default. This one works even before you sign in.
- **Bot Commands.** Greyed out until Twitch is connected. `!song` and `!last` are on for new installs. **Add a song.link** shows up once `!song` or `!last` is on. Turn on `!wolfwave`, add aliases, and set cooldowns.
- **Custom Commands.** Make your own commands. Each one can reply, post a plain message, or post an announcement. You can set these up before you connect; they reply once Twitch is connected.

Every command: [Bot Commands](/docs/bot-commands).

## Discord

<small>Open in WolfWave: [`wolfwave://settings/discord`](wolfwave://settings/discord)</small>

Show what you're listening to on your Discord profile.

- **Show on Discord.** The main switch. Off by default. The cards below it show up once it's on.
- **Profile Buttons.** **Show buttons** is on by default. While it's on, pick up to two: **Apple Music link** and **Any-app link (song.link)**. Both are on by default, and each row shows the link it will send.
- **Playlist.** **Show playlist** is off by default. When it's on, pick a **Display style**: **Artist + playlist line** (next to the artist) or **Playlist tooltip** (shown when someone hovers the app icon on Discord). Turn **Show playlist name** off and friends see a generic label. The name stays private.
- **When the music isn't playing.** Two choices, one per case:
  - **When you pause:** **Keep the song** (default) or **Hide the song**. A hidden song shows your "When music stops" choice.
  - **When music stops:** **Listening to WolfWave** (default) or **Nothing**.
- **Preview.** How your profile will look. Its chip reads **Live**, **Paused**, **Idle**, or **Offline**.

**If it won't connect, the pane tells you why:**

| Message | What to do |
|---|---|
| **Discord isn't running** | Open Discord. WolfWave connects on its own. |
| **Discord refused the connection** | Discord is running but said no. Restart Discord. |
| **WolfWave can't reach Discord** | macOS blocked the connection. Restart WolfWave. If it keeps happening, send a bug report. |
| **Not configured** | This build has no Discord app ID. Install the official release. |

The chip at the top gives the short version: **Connected**, **Connecting**, or one of **Discord not running**, **Refused**, and **Blocked**, which match the first three messages above.

More fixes: [Troubleshooting → Discord](/docs/troubleshooting#discord-not-connecting).

## Software Update

<small>Open in WolfWave: [`wolfwave://settings/software-update`](wolfwave://settings/software-update)</small>

- **Check Now** looks for a new version.
- **Check automatically** looks in the background.
- **Update Channel:** **Stable** (recommended) or **Nightly (dev)**. See [Nightly Builds](/docs/nightly).
- Installed with Homebrew? Updates come from Homebrew instead.

**Check for Updates…** is also in the menu bar's Help menu.

## Advanced

<small>Open in WolfWave: [`wolfwave://settings/advanced`](wolfwave://settings/advanced)</small>

- **Setup Wizard.** **Rerun Setup Wizard** opens the wizard again. Your settings don't change.
- **Diagnostics** (your logs).
  - **Export Logs** saves one file: your setup (version, macOS, install method), the last crash, and every log.
  - **Copy to Clipboard** and **Reveal in Finder**.
  - **Clear Logs** erases the logs and starts fresh.
- **Artwork Cache.** **Clear Artwork Cache** forgets saved album art links. They're fetched again as songs play.
- **Share Diagnostics.** Turn on **Collect on-device diagnostics** (off by default). Crash and performance reports stay on your Mac, and nothing is uploaded. WolfWave keeps the newest 50 from the last 30 days, and turning it off deletes them. The card also shows an **App launches** count (launches while it's on). **Reveal Diagnostics Folder** opens the reports in Finder.
- **Back Up Settings.** **Sync with iCloud**, **Export Settings**, and **Import Settings**. See [Back Up & Restore](/docs/backup).
- **Danger Zone.** **Erase All Data & Reset** wipes every setting, sign-in, log, and cache, then restarts. Can't be undone.

If WolfWave crashed last time, a **Recovered from a crash** note appears here once, with **Report a Bug…**.

## About

<small>Open in WolfWave: [`wolfwave://settings/about`](wolfwave://settings/about)</small>

- Version and build info, with a copy button.
- **Quick actions:** **Release Notes**, **Docs**, **Send Feedback**, and **Sponsor on GitHub**.
- **Show sponsor links.** On by default. Turn it off to hide the Sponsor items here, in the menu bar, and in the Help menu. WolfWave works the same either way.
- **Links & legal:** Privacy, Terms, and Acknowledgements.

## Deep links

A `wolfwave://` link opens Settings on a pane, scrolls to a card, and flashes it.

- It works whether Settings is open or closed.
- A link WolfWave doesn't know opens General. It never shows an error.

```text
wolfwave://settings                       General
wolfwave://settings/<pane>                one pane
wolfwave://settings/<pane>/<section>      one card inside that pane
```

The names below are fixed IDs, not the titles on screen, so links keep working when wording changes.

| Pane | `<pane>` | `<section>` |
|---|---|---|
| General | `general` | `music`, `visibility`, `appearance`, `notifications` |
| Song Requests | `song-requests` | `vote-skip`, `queue`, `access`, `queue-settings`, `playback`, `commands`, `redemptions`, `blocklist` |
| Stream Widgets | `stream-widgets` | `server`, `browser-source`, `appearance`, `custom-overlay` |
| Stream Deck | `stream-deck` | `control`, `token`, `setup` |
| History & Stats | `history-stats` | `tracking`, `stats-command`, `retention`, `danger-zone` |
| Twitch | `twitch` | `account`, `live-only`, `commands`, `custom-commands` |
| Discord | `discord` | `presence`, `buttons`, `playlist`, `behavior` |
| Software Update | `software-update` | `updates` |
| Advanced | `advanced` | `diagnostics`, `artwork-cache`, `backup`, `danger-zone` |
| About | `about` | |

Some cards only show once a feature is on. Song Requests cards (except `vote-skip`) need setup done and requests on. History cards (except `tracking`) need Listening History on, and `stats-command` also needs Show Stats & Charts. Discord cards (except `presence`) need Show on Discord on. A link to a hidden card opens the pane and stops there.

Try one from Terminal:

```bash
open "wolfwave://settings/twitch/custom-commands"
```
