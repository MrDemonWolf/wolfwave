**TL;DR:** WolfWave is Apple blue (`#0A84FF`) with a wolf-and-equalizer mark. Partner colors are only for partner logos. Copy is short and plain.

## Logo

WolfWave's canonical mark combines the wolf head with a padded side equalizer in [`assets/logo.svg`](https://github.com/MrDemonWolf/WolfWave/blob/main/assets/logo.svg). It is a two-part, `currentColor` SVG; the wolf silhouette is adapted from the CC0 [Wolf head Pinhead icon](https://commons.wikimedia.org/wiki/File:Wolf_head_Pinhead_icon.svg).

- Minimum size: 16×16 px for digital.
- In app chrome, use template rendering so the mark inherits the current foreground color.
- On standalone brand surfaces, use WolfWave blue (`#0A84FF`), white over a WolfWave blue background, or the approved theme-adaptive gradient: `AppConstants.Brand.wolfwaveGradientStart` → `AppConstants.Brand.wolfwaveGradientEnd` in Light and `AppConstants.Brand.wolfwaveGradientEnd` → `DSColor.brand300` in Dark. That gradient's tokens are filed under `color.partner` as `partner-wolfwave-gradient-*`, but it is WolfWave's own. Never use a partner's color.
- App-icon treatments keep about 10% padding around the mark on the brand-blue background. Debug and Release ship the same blue icon; the only thing Debug adds is a bottom-centre `DEV` badge, generated from `AppIcon.icon` by `scripts/generate-app-icons.ts` so the two can never drift.

## Partner colors

When showing third-party integrations (Twitch, Discord, Apple Music, OBS), use each partner's official color from `color.partner.*`. Never substitute or tint them. The one exception in that group is the `partner-wolfwave-gradient-*` pair, which is WolfWave's own gradient (see [Foundations](/docs/design-system/foundations#brand-gradient)).

| Partner | Token | Hex |
|---|---|---|
| Twitch | `partner-twitch` | `#9146FF` |
| Discord | `partner-discord` | `#5865F2` |
| Apple Music (gradient) | `partner-apple-music-start` → `end` | `#FF5D8B` → `#FA233B` |
| OBS Studio (gradient) | `partner-obs-start` → `end` | `#2C2C2E` → `#1A1A1C` |

## Voice

WolfWave is built for streamers. Text should be **short, punchy, jargon-free** (ADHD-friendly). Avoid:

- Long preambles. Lead with the verb.
- Apple-style marketing copy. We're not Apple.
- Technical jargon when a plain word works.

Prefer:

- "Connect Twitch" over "Set up Twitch integration".
- "Couldn't reach Discord" over "An error occurred while attempting to connect".
- Title case for buttons, menu items, section headers, and docs page titles ("Open System Settings", "Bot Commands"). Sentence case for banner titles, in-card labels, and captions ("Couldn't reach Discord", "Top artists"). Docs section headings are sentence case too.

## Don't

- Don't put WolfWave next to a partner logo so they look co-branded. WolfWave is the host, partners are services it talks to.
- Don't use partner colors as WolfWave brand accents. WolfWave brand = Apple blue.
- Don't add new top-level brand colors without a tokens.json PR + design review.
