**TL;DR:** one file, `design-system/tokens.json`, sets the colors, type, spacing, and motion for the app, this site, and the OBS widget.
This section is for contributors changing how WolfWave looks.

It covers three products:

- **The native macOS app** (Swift / SwiftUI, macOS 26 Liquid Glass)
- **This docs site** (Fumadocs / Tailwind 4)
- **The OBS widget overlay** (TypeScript / Tailwind 3, inlined into one HTML file)

## Canonical source

All tokens live in [`design-system/tokens.json`](https://github.com/MrDemonWolf/wolfwave/blob/main/design-system/tokens.json) at the repo root. A Bun script (`bun run tokens`) generates per-platform outputs that are committed alongside the source. Runtime consumers use those committed outputs; contributors rerun the generator after changing tokens or generator code.

```text
design-system/tokens.json   ← edit this
    │
    ├─→ Tokens.generated.swift     (DSColor, DSFont, DSSpace, DSRadius, …)
    ├─→ tokens.generated.css       (--ds-* custom properties)
    ├─→ widget-tokens.generated.js (window.WW_TOKENS)
    └─→ widget-themes.generated.ts (landing-page overlay preview)
```

## Change a token

1. Edit `design-system/tokens.json`.
2. Run `bun run tokens` to regenerate all four outputs.
3. Touched widget themes or layouts? Run `make widget` too.
4. Run `bun run ds:schema` and `bun run ds:lint`.
5. Commit the source and every regenerated file together. CI fails on drift.

Never hand-edit a `*.generated.*` file.

## Rules the linter enforces

`bun run ds:lint` blocks these in SwiftUI views:

- Literal font sizes. Use `DSFont.Size.*`.
- Literal `spacing:` or `.padding(N)`. Use `DSSpace.*`.
- Literal corner radii. Use `DSRadius.*`.
- Literal animation durations or spring responses. Use `DSMotion.*`.
- Raw system colors as a status tint. Use `DSColor.success` / `.warning` / `.error` / `.info` / `.neutral`.
