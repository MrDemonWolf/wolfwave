WolfWave's native macOS app ships a library of reusable SwiftUI components under
`apps/native/WolfWave/Views/Shared/` and `Views/Onboarding/Components/`. Every
component has a markdown catalog entry in
[`design-system/components/`](https://github.com/MrDemonWolf/wolfwave/tree/main/design-system/components)
covering its API, the tokens it uses, an anatomy diagram, accessibility notes,
and a do/don't list.

The catalog's
[README](https://github.com/MrDemonWolf/wolfwave/blob/main/design-system/components/README.md)
is the live index — it tracks every entry and its status, so it never drifts
from the source tree the way a copied table here would.

A few representative entries:

|---|---|---|
| `StatusChip` | Capsule indicator (dot + label) for connection state. | [entry](https://github.com/MrDemonWolf/wolfwave/blob/main/design-system/components/status-chip.md) |

## How to add a component

1. Build the SwiftUI view under `Views/Shared/` or `Views/Onboarding/Components/`.
2. Reference `DSColor` / `DSFont` / `DSSpace` / `DSRadius` tokens. No hardcoded numbers.
3. Add a markdown entry in `design-system/components/<name>.md` following the [template](https://github.com/MrDemonWolf/wolfwave/blob/main/design-system/components/README.md).
4. The catalog README's status table is the index — update it in the same change.
