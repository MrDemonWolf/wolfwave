## Set up in four steps

<SetupPath>
  <SetupStep href="/docs/installation" title="Install WolfWave">Download the app. A short setup wizard opens on first launch.</SetupStep>
  <SetupStep href="/docs/installation#apple-music" title="Allow Apple Music">One click, so WolfWave can see what's playing.</SetupStep>
  <SetupStep href="/docs/features#twitch-chat-bot" title="Connect Twitch">Sign in and join your channel. On a new install, `!song` and `!last` answer right away.</SetupStep>
  <SetupStep href="/docs/features#now-playing-widget" title="Add the overlay">Copy one link into OBS as a Browser Source.</SetupStep>
</SetupPath>
