The WolfWave Stream Deck plugin puts playback, your song-request queue, and your
integrations on physical keys. Keys aren't just buttons: they show live state, so
a glance tells you what's playing and how many requests are waiting.

<Callout type="warn">
  The plugin is not on the Elgato Marketplace yet. Until it is, you install it
  by hand from the repo.
</Callout>

## What you get

| Key | Does |
|---|---|
| Play / Pause | Plays or pauses Apple Music. Shows the current track. |
| Skip | Skips to the next track. |
| Hold Queue | Holds or resumes the request queue. Shows the queue size as a big number. |
| Approve Next | Approves the first request waiting for review. Turns amber with the pending count when requests are waiting. |
| Clear Queue | Empties the request queue. Shows the queue size. |
| Block Song | Adds the current song to your blocklist. |
| Overlay | Turns the stream overlay on or off. |
| Discord Presence | Turns Discord Rich Presence on or off. |
| Music Sync | Turns Apple Music tracking on or off. |
| Cycle Theme | Switches the overlay to the next theme. |
| Status | Four dots, one per link: **M**usic, **T**witch, **D**iscord, **O**verlay. Lit in the service's colour when it's up. Display only, pressing it does nothing. |

A key you can press turns solid blue while it's on, so playing, held, and every
toggle read from across the room. Clear Queue and Block Song are red because they
throw something away.

Hold Queue, Approve Next, Clear Queue, and Status draw their own numbers and dots,
so they leave the key title free — set your own label on them and it stays.

Approve Next only matters if you've turned on **Require My Approval** in
Settings → Song Requests → Access. See [Song Requests](/docs/features#song-requests).

## Install

1. Package the plugin from the repo:

   ```bash
   bun run --filter streamdeck pack
   ```

2. Double-click `apps/streamdeck/dist/com.mrdemonwolf.wolfwave.streamDeckPlugin`.
   The Stream Deck app installs it and asks you to confirm.

Prefer to work on the plugin itself? Run `bun run --filter streamdeck build` and
copy (or symlink) `apps/streamdeck/com.mrdemonwolf.wolfwave.sdPlugin` into
`~/Library/Application Support/com.elgato.StreamDeck/Plugins/`, then restart the
Stream Deck app.

## Connect it to WolfWave

Drag any WolfWave key onto a page and open its settings panel.

1. In WolfWave, go to Settings → Stream Deck and reveal **Stream Deck Control Token**.
2. Paste it into the **Control token** field.
3. Leave **Port** alone unless you changed the WebSocket port in WolfWave.
   The plugin always connects to WolfWave on this Mac.

The Stream Deck pane also has an **Allow Stream Deck commands** switch. It is on
by default. Turning it off makes WolfWave refuse every key press while leaving
your overlay on the air, which is the switch to reach for if you want the
now-playing box on stream but nothing able to drive playback.

You only do this once. Every WolfWave key shares the same connection.

Stream Deck and your overlay share one connection, so **Stream Widgets** has to
be on for keys to reach WolfWave. The Stream Deck pane says so, with a button
that takes you there, when it is off.
If you used protocol v1, copy the new control token once after updating. The old
shared access token is now the read-only overlay token and cannot run commands.

<Callout type="info">
  The plugin talks directly to WolfWave over a loopback-only control role, gated
  by its own control token. The overlay token is read-only. No third-party service
  is involved, no key press goes through the internet, and the plugin cannot be
  pointed at another Mac.
</Callout>

## What the keys tell you

| Key reads | Means |
|---|---|
| **Offline** | WolfWave isn't running, or the overlay server is off. The plugin keeps retrying. |
| **Token?** | The control token is missing, or isn't exactly 64 hexadecimal characters (`0`–`9`, `a`–`f`, `A`–`F`; case-insensitive). Re-copy **Stream Deck Control Token** from Stream Widgets. |
| **Update** | WolfWave and the plugin disagree on the control-protocol version — either one can be the older side. Update both to matching versions. |

A key flashes a checkmark when a press worked and an alert when it didn't —
pressing Approve Next with nothing pending, for example.

## Streamer Mode

[Streamer Mode](/docs/streamer-mode) masks both tokens in WolfWave's own windows.
It doesn't change what the plugin does, but you'll need to turn it off (or use
the reveal control) to copy the control token in the first place.
