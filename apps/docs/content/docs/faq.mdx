Quick answers to common questions. Each one links to the full page if you want more.

## The basics

<Accordions type="single">

<Accordion title="What does WolfWave do?">

WolfWave is a menu bar app for your Mac. It watches the Apple Music app and shares the song you're playing in three places:

- **Twitch chat.** Viewers type `!song` to see it, or `!sr` to request a song.
- **Discord.** Your profile shows "Listening to WolfWave" with the album art.
- **Your stream.** An overlay you add to OBS as a browser source.

See [Features](/docs/features) for everything it does.

</Accordion>

<Accordion title="What do I need to run it?">

- A Mac with Apple Silicon (M1 or later). Intel Macs aren't supported.
- macOS 26 (Tahoe) or newer.
- The Apple Music app. Song requests also need an Apple Music subscription.

Start with [Installation](/docs/installation).

</Accordion>

<Accordion title="Does it work with Spotify?">

No. WolfWave only works with the Apple Music app on your Mac. Viewers can paste a Spotify or YouTube link into `!sr`, and WolfWave finds that song on Apple Music. But it can't play from or read Spotify.

See how WolfWave stacks up against other Apple Music tools in the [comparison](/docs/comparison).

</Accordion>

<Accordion title="Is it really free?">

Yes. It's open source under the GPL-3.0 license. No paywall, no premium tier, no ads. The code is on [GitHub](https://github.com/MrDemonWolf/wolfwave). If you want to give back, see [Support](/docs/support).

</Accordion>

<Accordion title="Why isn't it on the Mac App Store?">

WolfWave needs sandbox exceptions to talk to Discord on your Mac, and the Mac App Store doesn't normally allow those. So it ships as a download instead. Every release is signed with a Developer ID and notarized by Apple.

</Accordion>

</Accordions>

## For your viewers

<Accordions type="single">

<Accordion title="What can my viewers type in chat?">

The full list, with example replies, is on [What can I type in chat?](/docs/bot-commands#what-can-i-type-in-chat). Share that link with your community.

</Accordion>

<Accordion title="Why don't my chat commands reply?">

Most commands start **off**, and `!sr` also needs Song Requests turned on. Other common causes are cooldowns and the "Only reply while live" switch. Go through the checklist in [Troubleshooting](/docs/troubleshooting#commands-not-replying).

</Accordion>

<Accordion title="Can I approve song requests before they play?">

Yes. Turn on **Require My Approval** in Settings → Song Requests. Every request waits until you approve or decline it. It's off by default. See [Song requests](/docs/features#song-requests).

</Accordion>

<Accordion title="Can viewers request with channel points or Bits?">

Yes, if your channel is Twitch Affiliate or Partner. WolfWave can add a **Request a Song** reward, take song names in Bit cheers, and let a cheer move a viewer's song to the front. You must sign in with your broadcaster account for this. See [Channel points and Bits](/docs/bot-commands#channel-points-and-bits).

</Accordion>

<Accordion title="My !playlist link stopped working">

The playlist was deleted, or its sharing was turned off in Apple Music. WolfWave notices, turns `!playlist` off so chat never gets a broken link, and shows a fix-it banner in Settings → Song Requests. Requests keep working the whole time.

</Accordion>

</Accordions>

## Streaming

<Accordions type="single">

<Accordion title="Will it slow down my stream?">

It's built to stay light:

- It reacts to the Music app's own "song changed" signals instead of asking over and over.
- A backup check runs every 5 seconds, and slower in Low Power Mode.
- The overlay's progress updates only run while an overlay is connected and a song is playing.

</Accordion>

<Accordion title="Can I use it with OBS on a second PC?">

Yes. The overlay can be reached from another computer on your home network. Settings → Stream Widgets shows a network address for it. That address includes your overlay token, so keep it private. If it leaks, make a new token.

Stream Deck control is different: it only works from the same Mac. See [Security](/docs/security#websocket-server-security).

</Accordion>

<Accordion title="Can I build my own overlay?">

Yes. The overlay data is plain JSON over a WebSocket: song, artist, album, artwork URL, length, elapsed time, and play state. The message format is in [OBS Widget](/docs/widget#message-contract).

</Accordion>

<Accordion title="What is Streamer Mode?">

One switch that hides private values in WolfWave's windows, like your channel name, addresses, and tokens, so the app is safe to show on camera. It only changes what's on screen. Everything keeps working. See [Streamer Mode](/docs/streamer-mode).

</Accordion>

</Accordions>

## Privacy and security

<Accordions type="single">

<Accordion title="Is my Twitch sign-in safe?">

Yes.

- You sign in on Twitch's own website with a short code. Your password never touches WolfWave.
- Your sign-in is stored in the macOS Keychain, the same place Safari keeps passwords.
- The app runs in Apple's App Sandbox.

</Accordion>

<Accordion title="Does WolfWave send my data anywhere?">

There is no WolfWave server, and no analytics. WolfWave only talks to:

- Twitch and Discord, if you connect them.
- Apple, for song lookups, artwork, and song requests.
- Spotify and YouTube, only to read the title of a link a viewer pasted into `!sr`.
- iCloud, only if you turn on **Sync with iCloud**.
- GitHub, to check for updates.

**Diagnostics** (Settings → Advanced) is off by default. When on, it keeps Apple's crash and hang reports on your Mac. Nothing is uploaded. See the [Privacy Policy](/docs/privacy-policy).

</Accordion>

<Accordion title="Where is my listening history stored?">

On your Mac, in a local file. Listening History is off by default, nothing is uploaded, and you can clear it any time. See [Listening History](/docs/listening-history).

</Accordion>

<Accordion title="Is it safe to show the overlay address on stream?">

The same-Mac address (`http://localhost:…`) has no token in it, so it's safe. The network address for a second PC includes `?token=…`, so keep that one private. Turn on [Streamer Mode](/docs/streamer-mode) to hide it on screen.

</Accordion>

</Accordions>

## Updates and help

<Accordions type="single">

<Accordion title="How do updates work?">

WolfWave updates itself with Sparkle, a common Mac updater. Every update is signed and checked before it installs.

- **Stable** is the default channel.
- **Nightly** is opt-in and gets new changes first. See [Nightly builds](/docs/nightly).
- To check by hand: menu bar icon → Help → **Check for Updates…**

Installed with Homebrew? Run `brew upgrade wolfwave` instead. The built-in updater turns itself off.

</Accordion>

<Accordion title="Where do I get help?">

- [Troubleshooting](/docs/troubleshooting). Fixes for every error message.
- [Discord community](https://mrdwolf.net/discord). The fastest way to reach a person.
- [GitHub Issues](https://github.com/MrDemonWolf/wolfwave/issues). For bugs. See [how to report a bug](/docs/support#report-a-bug).

</Accordion>
