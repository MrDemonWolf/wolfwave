**TL;DR:** Nightly gives you the newest WolfWave builds before they're released. It's for streamers who want to help test. Everyone else should stay on Stable, the default.

## Stable vs Nightly

| | Stable | Nightly |
|---|---|---|
| **What you get** | Tested releases | The newest builds off `main` |
| **How often** | Each release | Up to once a night |
| **Bugs** | Rare | Expect some |
| **Support** | Yes | No, but bug reports are welcome |

## Switch to Nightly

1. Open **Settings → Software Update**.
2. Under **Update Channel**, pick **Nightly (dev)**.
3. Read the warning and click **Switch to Nightly**.

WolfWave checks the nightly feed right away. After that, update checks pull nightly builds.

## Go back to Stable

1. Open **Settings → Software Update**.
2. Under **Update Channel**, pick **Stable**.

WolfWave never offers a version *lower* than the one you have. So switching alone doesn't move you back. It puts you in line for the next stable release.

To get back right now, download and install the latest [Stable build](/docs/installation).

## What to know

- **Same signing.** Nightly builds carry the same Developer ID signature and Apple notarization as Stable.
- **Built around midnight Chicago time**, but only on days the app changed. Docs-only days skip the build.
- **Named for what's coming.** A nightly reads like `2.2.0-nightly+a1b2c3d`. That's the release the changes are heading into, not one that already shipped.
- **Your choice sticks.** You stay on Nightly across updates until you switch back.
- **Homebrew installs can't use it.** Homebrew manages updates, so the picker is hidden. Run `brew upgrade wolfwave` for the stable cask.

<Callout type="warn">
  **Grabbed the August 5, 2026 nightly? Reinstall once.** That build (`2.1.0-nightly+4c36bef`) shipped with a build number so high that no later build can pass it, so it never updates itself. Download the latest [Stable](/docs/installation) or nightly DMG once and you're fixed. The numbering bug is fixed and won't come back.
</Callout>
