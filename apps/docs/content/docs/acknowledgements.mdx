**TL;DR:** WolfWave is built on other people's work. This page lists the services it talks to, the open-source code it ships, and whose trademarks are whose.

A short version of this list is in the app under **Settings → About → Acknowledgements**. Its **View full licenses and notices** link opens this page.

## Third-Party Services

WolfWave is a client of the following services. Your use of each is governed by that service's terms.

| Service | Used for | Terms |
| --- | --- | --- |
| **Twitch** | EventSub WebSocket subscriptions, Helix chat + channel-point + bits APIs, OAuth Device Code flow | [Terms](https://www.twitch.tv/p/legal/terms-of-service/) · [Developer Agreement](https://www.twitch.tv/p/legal/developer-agreement/) |
| **Discord** | Local IPC Rich Presence over Unix domain socket | [Terms](https://discord.com/terms) · [Developer Terms](https://discord.com/developers/docs/policies-and-agreements/developer-terms-of-service) |
| **Apple Music** | Playback monitoring via ScriptingBridge + MusicKit search | [Apple Media Services Terms](https://www.apple.com/legal/internet-services/itunes/) |
| **Odesli (song.link)** | Link target only. WolfWave builds `song.link` URLs that open in the viewer's browser; it makes no API calls to Odesli | [Terms](https://song.link/terms) |
| **Spotify** | oEmbed metadata for Spotify links pasted as song requests | [Terms](https://www.spotify.com/legal/end-user-agreement/) |
| **YouTube** | oEmbed metadata for YouTube links pasted as song requests | [Terms](https://www.youtube.com/t/terms) |
| **iTunes Search API** | Album artwork lookup and Apple Music URL resolution | [Apple API terms](https://www.apple.com/legal/internet-services/itunes/) |
